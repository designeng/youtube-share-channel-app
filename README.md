# Channel Viewer

Мобильное приложение (Expo SDK 58 / React Native 0.88): делитесь ссылкой на YouTube‑канал через системное меню **Поделиться**, и приложение показывает только видео этого канала. Внутри: главы, транскрипт и подробные AI‑обзоры по главам.

## Возможности

| # | Функция | Как реализовано |
|---|---------|-----------------|
| 1 | Приём ссылки через Share | `expo-share-intent`: на Android — intent-filter `SEND text/*`, на iOS — Share Extension. Понимает `@handle`, `/channel/UC…`, `/c/…`, `/user/…`, а также ссылку на видео (откроется канал автора). |
| 2 | Список видео | YouTube Data API v3: uploads-плейлист плюс `videos.list`. Миниатюры, длительность, даты, просмотры. Вкладки «Видео / Shorts / Трансляции / Все». Сортировка: новые, старые, популярные, длинные, А–Я. Поиск по названию. |
| 3 | Плеер | Официальный YouTube IFrame Player API в WebView ([YouTubePlayer.tsx](src/components/YouTubePlayer.tsx)). |
| 4 | Описание и главы | Описание с кнопкой «ещё…». Главы парсятся из таймкодов в описании, как это делает сам YouTube. Нажатие на таймкод перематывает видео. Если глав нет, видео делится на части по ~10 минут. |
| 5 | Транскрипт | Выбор дорожки или автоперевода YouTube на заданный язык ([transcript.ts](src/lib/transcript.ts)). |
| 6 | AI‑обзоры | Gemini (бесплатный тариф) или OpenRouter (`:free`‑модели): обзор одной главы, всех глав по очереди или всего видео. Промпт заточен под подробный пересказ с фактами, цифрами и кликабельными таймкодами ([ai.ts](src/lib/ai.ts)). Результаты кэшируются. |

## Запуск

Share Extension и intent-фильтры — нативный код, поэтому **Expo Go не подойдёт**, нужен development build:

```bash
npm install
npx expo run:android      # или: npx expo run:ios  (нужен Xcode)
# либо облачная сборка: npx eas-cli@latest build --profile development
```

Затем в приложении откройте ⚙︎ и укажите ключи:

- **YouTube Data API v3 key** (обязателен): [Google Cloud Console](https://console.cloud.google.com/apis/library/youtube.googleapis.com) → включить API → Credentials → API key. Бесплатно 10 000 единиц квоты в день; одна страница из 50 видео стоит 2 единицы.
- **Gemini API key** ([AI Studio](https://aistudio.google.com/apikey)) **или** **OpenRouter key** ([openrouter.ai/keys](https://openrouter.ai/keys)).
- Модель можно выбрать кнопкой «Выбрать»: список подгружается из API, потому что каталоги бесплатных моделей часто меняются. По умолчанию стоят `gemini-flash-latest` и `openrouter/free`.

Ключи хранятся в `expo-secure-store` (Keychain / Keystore).

## Ограничения (важно)

**Транскрипты.** Официальный способ `captions.download` из Data API позволяет скачивать субтитры **только владельцу видео** (OAuth). Для чужих видео приложение использует внутренние эндпоинты YouTube, те же, что у сайта и приложения:
1. `youtubei/v1/player` (клиент ANDROID) → `captionTracks` → `timedtext` (json3);
2. фолбэк: HTML страницы видео → `ytInitialPlayerResponse`;
3. фолбэк: `youtubei/v1/get_transcript` (панель «Показать текст»).

Последствия:
- API недокументирован и может сломаться без предупреждения. Чаще всего помогает поднять `clientVersion` в `transcript.ts`. С точки зрения ToS YouTube это серая зона.
- Транскрипт есть только при наличии субтитров (ручных или автоматических).
- **Перевод в выбранную локаль** (`tlang`) YouTube строго ограничивает по частоте запросов (HTTP 429). В этом случае показывается оригинал. На практике это не страшно: AI пишет обзор на выбранном языке по оригинальному транскрипту, а это даже точнее машинного перевода.

**Без субтитров.** Gemini умеет «смотреть» само видео по YouTube‑ссылке, только публичное и с обрезкой по границам главы. На бесплатном тарифе действует дневной лимит на часы видео. OpenRouter без транскрипта не работает.

**Плеер.** Если автор запретил встраивание (ошибки 101/150), показывается кнопка «Открыть в YouTube».

**Сортировка и поиск** работают по загруженным видео. У больших каналов нажмите «Загрузить все» (лимит — 2000 видео, ≈80 единиц квоты). Поиск через `search.list` не используется: он стоит 100 единиц за запрос.

**Бесплатные AI‑тарифы** ограничены по RPM. Режим «все главы по очереди» автоматически повторяет запрос при 429.

## Структура

```
src/app/            экраны (Expo Router)
  _layout.tsx       провайдеры + приём Share intent
  +native-intent.ts перенаправление deep link от iOS Share Extension
  index.tsx         главная: недавние каналы, вставка ссылки
  open.tsx          резолв ссылки → канал
  channel/[id].tsx  список видео
  video/[id].tsx    плеер, описание, главы, транскрипт, AI
  settings.tsx      ключи, модель, языки
src/lib/
  parseUrl.ts       разбор ссылок YouTube
  youtubeApi.ts     Data API v3
  transcript.ts     субтитры (InnerTube)
  chapters.ts       парсинг глав, нарезка транскрипта
  ai.ts             Gemini / OpenRouter, промпты
  settings.tsx      настройки, кэш, недавние каналы
```
